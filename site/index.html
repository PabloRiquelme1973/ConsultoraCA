Preguntas frecuentes

Lo que necesitás saber.

Un estudio útil comienza por plantear correctamente el alcance y los objetivos.

¿Realizan encuestas digitales y presenciales?

Podemos diseñar investigaciones online, relevamientos territoriales o proyectos mixtos. El método se define según el público, la cobertura y el propósito del estudio.

¿Qué incluye la entrega de una investigación?

Según el proyecto, puede incluir bases depuradas, cruces de variables, informes ejecutivos, visualizaciones y recomendaciones para la toma de decisiones.

¿También desarrollan páginas web y aplicaciones?

Sí. Diseñamos sitios web profesionales, portales y sistemas a medida. También evaluamos automatizaciones e integraciones con inteligencia artificial, según los objetivos, la infraestructura y el presupuesto de cada proyecto.

¿Los tableros están conectados a datos reales?

El panel visible en esta web es una demostración con datos ficticios. La integración de un proyecto real requiere configurar encuestas, almacenamiento y accesos a sus propios resultados.

¿Pueden adaptar un estudio a una ciudad o barrio?

Sí. La cobertura territorial, el universo, el cuestionario y el diseño muestral deben definirse para cada investigación, así como las medidas para proteger los datos personales.
